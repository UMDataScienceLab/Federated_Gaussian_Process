# Federated_Gaussian_Process
Code for the paper "Federated Gaussian Process: Convergence, Automatic Personalization and Multi-Fidelity Modeling".

We propose FGPR, a federated Gaussian process regression framework in which clients jointly learn a global prior and then condition on their local data to obtain *personalized* predictions.
